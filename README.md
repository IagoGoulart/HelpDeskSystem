# 🎫 Help Desk System

Simulador de sistema de chamados (Help Desk) desenvolvido com **HTML, CSS e JavaScript puro**, focado em manipulação de DOM, lógica de aplicação e simulação de fluxo real de suporte técnico.

O projeto reproduz a dinâmica entre **cliente** e **atendente**, permitindo abertura, gerenciamento e atualização de tickets com persistência no navegador.

---

## 🚀 Demonstração do sistema

O fluxo simula um sistema real de suporte:

### 👤 Cliente

* Abre chamados
* Visualiza tickets
* Filtra por status

### 🛠 Atendente

* Visualiza todos os tickets
* Resolve chamados
* Cancela chamados
* Filtra por status

Todos os dados são armazenados em **localStorage**, simulando persistência sem backend.

---

## 🧠 Funcionalidades

* 🔐 Login simulado
* 🎫 Criação de tickets com título, categoria e descrição
* 📂 Listagem de chamados
* 🏷 Filtro por status (Aberto / Resolvido / Cancelado)
* 🔄 Atualização de status pelo atendente
* 💾 Persistência com localStorage
* 🎨 Interface responsiva
* 📱 Layout adaptado para mobile
* 🧩 Separação de responsabilidades por arquivos
